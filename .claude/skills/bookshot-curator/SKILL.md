# BookShot Curator

Превращает скриншоты и текст с рекомендациями книг в аккуратную подборку: название, автор, жанр — и группировку по авторам и жанрам. Работает вместе с приложением BookShot из этого репозитория, но полезен и сам по себе.

## Когда применять
- Пользователь прикрепил скриншот(ы) с книжными рекомендациями (чат, пост, заметки, список).
- Пользователь вставил текст со списком книг в свободной форме.
- Нужно добавить найденное в библиотеку BookShot или выгрузить CSV.

## Шаги

1. **Прочитай изображения.** Просмотри каждый скриншот сам. Если приложение под рукой, можно запустить `python -c "from ocr import extract_text; print(extract_text('<файл>'))"`, но свои глаза точнее на обложках, стикерах и необычных шрифтах.
2. **Извлеки книги.** Для каждой книги определи:
   - `title` — как написано, без кавычек и нумерации;
   - `author` — полное имя в формате «Имя Фамилия» (для «Оруэлл» → «Джордж Оруэлл»); если автора на скриншоте нет и ты не уверен, пиши «Автор не указан», а не угадывай;
   - `genre` — ровно один из списка: Классика, Проза, Фантастика, Фэнтези, Антиутопия, Детектив, Психология, Саморазвитие, Бизнес, Научпоп, История, Другое.
3. **Помечай сомнения.** Если OCR или текст нечёткие, не придумывай книгу: вынеси такие строки отдельным списком «Не уверена» и спроси пользователя.
4. **Не дублируй.** Одна книга — одна запись, даже если она встречается на нескольких скриншотах. Сравнивай без учёта регистра.
5. **Покажи результат** таблицей и двумя группировками: «По авторам» и «По жанрам». Сначала итог, потом сомнения.
6. **Добавь в библиотеку (если просили).**
   - Через интерфейс: `python app.py` → загрузить скриншоты на http://127.0.0.1:5000.
   - Или без интерфейса, через Python:
     ```python
     from app import create_app, _insert_book
     import sqlite3
     app = create_app()
     conn = sqlite3.connect(app.config["DB_PATH"])
     _insert_book(conn, "1984", "Джордж Оруэлл", "Антиутопия", None); conn.commit()
     ```
   - Экспорт: `GET /export.csv`.

## Формат ответа
```
Нашла N книг на M скриншотах.

| Название | Автор | Жанр |
|---|---|---|

По авторам: …
По жанрам: …
Не уверена: … (если есть)
```

## Чего не делать
- Не выдумывай книги, авторов и жанры, которых нет на скриншоте. «Другое» лучше неверного жанра.
- Не копируй описания и отрывки из книг, нужны только метаданные.
- Не коммить `data/` и личные скриншоты пользователя в репозиторий.
