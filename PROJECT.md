# BookShot — описание проекта

## 1. Название и одна фраза
**BookShot** — приложение, которое превращает скриншоты с рекомендациями книг в упорядоченную библиотеку: по авторам и по жанрам.

## 2. Проблема
Я много читаю и постоянно делаю скриншоты рекомендаций: из Telegram-чатов, постов в Instagram, подборок в заметках. Скриншоты оседают в галерее телефона. Через месяц невозможно ответить на простые вопросы: что я хотела прочитать? Какие книги одного автора я уже сохраняла? Что у меня есть из фантастики?

## 3. Для кого
Активные читатели, которые собирают рекомендации «на потом» в виде скриншотов, и не хотят вручную перепечатывать названия в трекер.

## 4. Решение
1. Пользователь загружает один или несколько скриншотов.
2. OCR (Tesseract) достаёт текст, парсер находит пары «название + автор».
3. Пользователь проверяет и правит результат на экране проверки.
4. Книги попадают в библиотеку, где их можно смотреть по авторам, по жанрам и общим списком, отмечать прочитанными и экспортировать в CSV.

## 5. Аналоги и отличие
| | Bookmory | Leero | BookShot |
|---|---|---|---|
| Назначение | трекер чтения: таймер, цели, заметки | трекер чтения: сессии, цели, статистика | **сбор рекомендаций из скриншотов** |
| Как добавить книгу | поиск, штрихкод, вручную | поиск, штрихкод, вручную | **загрузить скриншот** (+ вручную) |
| Группировка | коллекции, теги | коллекции | **авторы и жанры автоматически** |

Это не конкурент трекерам чтения, а «входная воронка» перед ними: сначала собрать, потом читать и отслеживать. (Данные об аналогах — из описаний в App Store, ноябрь 2026.)

## 6. Функции
**MVP (сделано):**
- загрузка нескольких скриншотов (PNG/JPG/WebP) и ввод текста вручную;
- OCR на русском и английском;
- парсинг форматов ««Название» — Автор», «Автор - Название», «Название, Автор», «Title by Author», нумерация и маркеры, переносы строк;
- склейка вариантов имени автора через встроенный справочник («Оруэлл» → «Джордж Оруэлл»);
- подсказка жанра по известным авторам;
- экран проверки с редактированием перед сохранением;
- библиотека: по авторам / по жанрам / все книги, поиск, фильтр по жанру;
- статус «прочитано», удаление, ручное добавление, экспорт CSV;
- защита от дублей.

**Дальше:**
- обогащение через Open Library / Google Books API: обложка, год, точный жанр, описание;
- мобильное приложение (или PWA) с «Поделиться → BookShot» прямо из галереи;
- LLM-распознавание (vision) вместо правил — для сложных скриншотов с обложками;
- пользовательские полки и теги, аккаунты и синхронизация;
- ссылки «где купить / читать».

## 7. Пользовательский сценарий
Увидела подборку в канале → сделала скриншот → вечером открыла BookShot, выбрала 5 скриншотов → проверила найденное → сохранила → в разделе «Психология» увидела всё, что собрала.

## 8. Технологии
Python 3.13, Flask, SQLite, Tesseract OCR (pytesseract + Pillow), Jinja-шаблоны, чистый CSS. Тесты — pytest. Скриншоты для README — Playwright.
Причина выбора: минимум зависимостей, всё работает локально и бесплатно, данные остаются у пользователя.

## 9. Данные
Две таблицы SQLite: `screenshots` (файл, распознанный текст) и `books` (название, автор, жанр, прочитано, ссылка на скриншот). Уникальность — по паре «название + автор» без учёта регистра.

## 10. Критерии успеха MVP
- Из типичного скриншота с 5–10 книгами верно находится ≥ 80 % записей, остальное правится за пару кликов.
- От загрузки до готовой библиотеки — меньше минуты.

## 11. Риски
| Риск | Что делаем |
|---|---|
| OCR путает шрифты и фон | увеличение изображения; экран проверки; позже vision-LLM |
| Свободный формат текста | эвристики + тесты на реальные паттерны, ручная правка |
| Справочник авторов маленький | подключить Open Library API |
| Авторские права на скриншоты | в репозитории только сгенерированные учебные примеры |
