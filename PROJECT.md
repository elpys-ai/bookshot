# BookShot — описание проекта

Структура описания взята из урока «CLm04 Итоговый проект».

## Название
**BookShot** — «Библиотека из скриншотов: книги по авторам и жанрам».

## Проблема
Я много читаю и постоянно делаю скриншоты с рекомендациями книг: из Telegram-чатов, постов в Instagram, подборок в заметках. Скриншоты оседают в галерее телефона и теряются. Через месяц невозможно ответить на простые вопросы: что я хотела прочитать? Какие книги одного автора я уже сохраняла? Что у меня есть из фантастики или психологии?

Существующие трекеры чтения (Bookmory, Leero) помогают следить за процессом чтения, но книги в них добавляются поиском, штрихкодом или вручную. Перепечатывать названия со скриншотов никто не хочет, поэтому рекомендации остаются в галерее.

## Пользователь
Активные читатели, которые собирают рекомендации «на потом» в виде скриншотов. Это личный инструмент: для себя, для книжных клубов, для тех, кто ведёт читательские списки или канал с подборками.

## Основная функция
Что подаётся на вход, что делает сервис, что получается на выходе:

1. **Вход:** один или несколько скриншотов (PNG, JPG, WebP) или текст, вставленный вручную.
2. **Распознавание:** OCR (Tesseract, русский + английский) достаёт текст со скриншота.
3. **Разбор:** парсер находит пары «название + автор» в форматах ««Название» — Автор», «Автор - Название», «Название, Автор», «Title by Author», учитывает нумерацию, маркеры и переносы строк.
4. **Нормализация:** варианты имени автора склеиваются через встроенный справочник («Оруэлл» → «Джордж Оруэлл»), жанр подсказывается по известным авторам.
5. **Проверка человеком:** экран, где можно исправить название, автора и жанр или убрать лишнее.
6. **Сохранение:** книги попадают в библиотеку (SQLite) без дублей.

## Формат результата
Веб-страница с библиотекой, которую можно смотреть тремя способами: **по авторам**, **по жанрам** и общим списком. Есть поиск, фильтр по жанру, отметка «прочитано», удаление, ручное добавление книги и экспорт всей библиотеки в CSV.

## Минимальный функционал (MVP)
Сделано в первой версии:
- загрузка нескольких скриншотов и ввод текста вручную;
- OCR на русском и английском;
- парсинг основных форматов строк, склейка переносов;
- справочник известных авторов и жанров;
- экран проверки с редактированием перед сохранением;
- библиотека по авторам / жанрам / списком, поиск, фильтр;
- «прочитано», удаление, ручное добавление, экспорт CSV;
- защита от дублей, 24 автотеста.

Планируется в будущих версиях:
- Open Library / Google Books API: обложки, год, точный жанр, описание;
- PWA и пункт «Поделиться → BookShot» прямо из галереи телефона;
- распознавание через vision-модель вместо правил, чтобы читать обложки и сложные макеты;
- свои полки и теги, аккаунты и синхронизация между устройствами.

## Технологии
Python 3.13, Flask, SQLite (встроенный `sqlite3`), Tesseract OCR (pytesseract + Pillow), шаблоны Jinja, чистый CSS без фреймворков. Тесты — pytest. Скриншоты для README снимает Playwright.

Почему так: минимум зависимостей, всё работает локально и бесплатно, данные остаются у пользователя.

## Дополнительно

### Пользовательский сценарий
Увидела подборку в канале → сделала скриншот → вечером открыла BookShot, выбрала 5 скриншотов → проверила найденное → сохранила → в разделе «Психология» увидела всё, что собрала.

### Аналоги и отличие
| | Bookmory | Leero | BookShot |
|---|---|---|---|
| Назначение | трекер чтения: таймер, цели, заметки | трекер чтения: сессии, цели, статистика | **сбор рекомендаций из скриншотов** |
| Как добавить книгу | поиск, штрихкод, вручную | поиск, штрихкод, вручную | **загрузить скриншот** (+ вручную) |
| Группировка | коллекции, теги | коллекции | **авторы и жанры автоматически** |

BookShot не конкурирует с трекерами чтения, а стоит перед ними: сначала собрать рекомендации, потом читать и отслеживать. Данные об аналогах — из описаний в App Store, ноябрь 2026.

### Критерии успеха MVP
- Из типичного скриншота с 5–10 книгами верно находится не менее 80 % записей, остальное правится за пару кликов.
- От загрузки до готовой библиотеки проходит меньше минуты.

### Риски
| Риск | Что делаем |
|---|---|
| OCR путает шрифты и фон | увеличение изображения; экран проверки; позже vision-модель |
| Свободный формат текста | эвристики + тесты на реальные паттерны, ручная правка |
| Справочник авторов маленький | подключить Open Library API |
| Авторские права на скриншоты | в репозитории только сгенерированные учебные примеры |
